# Profile-Specific Starting Documents

These files are non-published starting documents for derived repositories. Select the closest profile, copy its file to `content/index.md` in the **separate private derived repository**, and adapt it to the source material.

They are not examples of completed operational authority. Every placeholder must be replaced or the unused module removed. Document identity, creator, ownership, revision, approval, repository intelligence, and release validation remain mandatory.

The canonical IaT Docs Engine repository repository must retain its comprehensive generic `content/index.md`; do not replace it with one of these profile files.
